# Review guidelines for `tests/`

Distilled from 90 upstream review comments (2016-11-01 → 2026-07-14) by gpt-6-astra. Each rule links the PRs it came from.

- **TESTS-01** Remove test-only constants, class wrappers, attributes, rebinding, and assertions that do not contribute to the behavior under test. _Why:_ unnecessary scaffolding obscures the test. _Sources:_ [4560](https://github.com/pallets/flask/pull/4560#discussion_r861198993) [3814](https://github.com/pallets/flask/pull/3814#discussion_r513547442) [3814](https://github.com/pallets/flask/pull/3814#discussion_r513520907) [3814](https://github.com/pallets/flask/pull/3814#discussion_r513520314) [2325](https://github.com/pallets/flask/pull/2325#discussion_r118293816)
- **TESTS-02** Give regression tests inputs and expected results that distinguish the reported bug from unrelated failures or already-covered cases. _Why:_ a passing test must demonstrate the intended fix. _Sources:_ [5775](https://github.com/pallets/flask/pull/5775#discussion_r2210480316) [4479](https://github.com/pallets/flask/pull/4479#discussion_r835554749) [4160](https://github.com/pallets/flask/pull/4160#discussion_r654803349) [2211](https://github.com/pallets/flask/pull/2211#discussion_r106771232) [2211](https://github.com/pallets/flask/pull/2211#discussion_r106771227)
- **TESTS-03** Test the smallest Flask-owned behavior involved, using response objects or hook return values directly when routing or template rendering is irrelevant. _Why:_ extra integration setup can merely retest dependencies. _Sources:_ [4840](https://github.com/pallets/flask/pull/4840#discussion_r998530715) [4036](https://github.com/pallets/flask/pull/4036#discussion_r631778526) [3181](https://github.com/pallets/flask/pull/3181#discussion_r283352536) [2303](https://github.com/pallets/flask/pull/2303#discussion_r117878248) [2303](https://github.com/pallets/flask/pull/2303#discussion_r117878213)
- **TESTS-04** Exercise request behavior through the test client and serialization or representation through normal public entry points rather than manually invoking internals. _Why:_ realistic calls cover the actual execution path. _Sources:_ [5775](https://github.com/pallets/flask/pull/5775#discussion_r2210481637) [5775](https://github.com/pallets/flask/pull/5775#discussion_r2210476844) [4160](https://github.com/pallets/flask/pull/4160#discussion_r654911700) [3814](https://github.com/pallets/flask/pull/3814#discussion_r513522695) [2807](https://github.com/pallets/flask/pull/2807#discussion_r191314595)
- **TESTS-05** Use pytest monkeypatching for environment or global changes, bound its lifetime to the test, and preserve separate context lifetimes when refactoring cases. _Why:_ state must not leak between cases. _Sources:_ [6095](https://github.com/pallets/flask/pull/6095#discussion_r3578284779) [6095](https://github.com/pallets/flask/pull/6095#discussion_r3578161016) [2306](https://github.com/pallets/flask/pull/2306#discussion_r117916488) [2303](https://github.com/pallets/flask/pull/2303#discussion_r117878177)
- **TESTS-06** Parameterize repeated input/output cases with separate, descriptive input and expected-result parameters instead of sequential mutations and assertions. _Why:_ each case gets an independent run and clear expectation. _Sources:_ [3786](https://github.com/pallets/flask/pull/3786#discussion_r502854024) [2303](https://github.com/pallets/flask/pull/2303#discussion_r118015099) [2303](https://github.com/pallets/flask/pull/2303#discussion_r118014882) [2303](https://github.com/pallets/flask/pull/2303#discussion_r117898697)
- **TESTS-07** Preserve existing tests and setup that exercise distinct behavior when adding regressions or reorganizing coverage. _Why:_ new coverage must not silently replace old coverage. _Sources:_ [5775](https://github.com/pallets/flask/pull/5775#discussion_r2210469867) [3814](https://github.com/pallets/flask/pull/3814#discussion_r513548049) [3181](https://github.com/pallets/flask/pull/3181#discussion_r283352536)
- **TESTS-08** Keep ordinary imports at module scope, put each imported name on its own line without gratuitous blank lines, and use qualified Hypothesis names. _Why:_ imports should remain consistent and traceable. _Sources:_ [5775](https://github.com/pallets/flask/pull/5775#discussion_r2210471389) [3510](https://github.com/pallets/flask/pull/3510#discussion_r382200065) [2073](https://github.com/pallets/flask/pull/2073#discussion_r86021508)
- **TESTS-09** Use direct truth assertions, `is None` for null checks, and `pytest.raises` for expected exceptions. _Why:_ pytest idioms make expectations explicit. _Sources:_ [2303](https://github.com/pallets/flask/pull/2303#discussion_r117898172) [2303](https://github.com/pallets/flask/pull/2303#discussion_r117898097) [2222](https://github.com/pallets/flask/pull/2222#discussion_r107735297)
- **TESTS-10** Keep test modules and sample applications syntactically valid on every Python version supported by the target branch. _Why:_ incompatible syntax can prevent collection of an entire file. _Sources:_ [3512](https://github.com/pallets/flask/pull/3512#discussion_r382929021) [3195](https://github.com/pallets/flask/pull/3195#discussion_r283246605) [2123](https://github.com/pallets/flask/pull/2123#discussion_r93832691)
- **TESTS-11** Write invisible characters as escape sequences, choose quote delimiters that avoid unnecessary escaping, and remove accidental adjacent string literals. _Why:_ test strings must visibly represent their intended contents. _Sources:_ [5525](https://github.com/pallets/flask/pull/5525#discussion_r1672135455) [2807](https://github.com/pallets/flask/pull/2807#discussion_r191418995) [2223](https://github.com/pallets/flask/pull/2223#discussion_r110522558)
- **TESTS-12** Parse structured header values with `parse_options_header` and compare the resulting options dictionary against decoded expected values. _Why:_ assertions should check header semantics rather than raw formatting. _Sources:_ [2223](https://github.com/pallets/flask/pull/2223#discussion_r110522590) [2223](https://github.com/pallets/flask/pull/2223#discussion_r110521709) [2223](https://github.com/pallets/flask/pull/2223#discussion_r110456139)
- **TESTS-13** Reuse the shared `app` fixture and pytest temporary-directory fixtures instead of constructing equivalent custom setup. _Why:_ established fixtures reduce duplicated lifecycle management. _Sources:_ [5775](https://github.com/pallets/flask/pull/5775#discussion_r2210472310) [2306](https://github.com/pallets/flask/pull/2306#discussion_r117911664)
- **TESTS-14** Skip tests requiring missing optional dependencies with `pytest.importorskip` or a shared conditional skip for the affected group. _Why:_ the remaining suite should run without optional packages. _Sources:_ [3398](https://github.com/pallets/flask/pull/3398#discussion_r334991098) [2306](https://github.com/pallets/flask/pull/2306#discussion_r117920473)
