# Review guidelines for `docs/`

Distilled from 157 upstream review comments (2016-12-19 → 2026-01-15) by gpt-6-astra. Each rule links the PRs it came from.

- **DOCS-01** State the trigger, affected object, and request or application scope of documented behavior, and name specific features rather than saying “all development features”. _Why:_ precise conditions prevent misleading explanations. _Sources:_ [5722](https://github.com/pallets/flask/pull/5722#discussion_r2283132069) [5722](https://github.com/pallets/flask/pull/5722#discussion_r2283123541) [2570](https://github.com/pallets/flask/pull/2570#discussion_r159909866) [2436](https://github.com/pallets/flask/pull/2436#discussion_r130206161) [2307](https://github.com/pallets/flask/pull/2307#discussion_r117900448)
- **DOCS-02** Explain how environment files are created per installation and loaded in development and deployment, without encouraging secret-bearing `.env` files to be committed or assuming they ship with installed packages. _Why:_ deployment cannot depend on local repository configuration. _Sources:_ [2164](https://github.com/pallets/flask/pull/2164#discussion_r98363450) [2164](https://github.com/pallets/flask/pull/2164#discussion_r98362230) [2164](https://github.com/pallets/flask/pull/2164#discussion_r98361934) [2164](https://github.com/pallets/flask/pull/2164#discussion_r98361786) [2164](https://github.com/pallets/flask/pull/2164#discussion_r98361719)
- **DOCS-03** Keep example variables defined, pass the types downstream APIs expect, serialize supported values, and preserve the intended HTTP status in error responses. _Why:_ copied examples must behave as described. _Sources:_ [3824](https://github.com/pallets/flask/pull/3824#discussion_r515991306) [3260](https://github.com/pallets/flask/pull/3260#discussion_r292949662) [3260](https://github.com/pallets/flask/pull/3260#discussion_r292934697) [2982](https://github.com/pallets/flask/pull/2982#discussion_r232660177) [2982](https://github.com/pallets/flask/pull/2982#discussion_r232506068)
- **DOCS-04** Remove repeated warnings, unnecessary setup steps, and historical-change commentary that does not help readers perform the current task. _Why:_ introductory guidance should not accumulate distractions. _Sources:_ [5722](https://github.com/pallets/flask/pull/5722#discussion_r2283131361) [4840](https://github.com/pallets/flask/pull/4840#discussion_r998516903) [2991](https://github.com/pallets/flask/pull/2991#discussion_r231647015) [2990](https://github.com/pallets/flask/pull/2990#discussion_r231645001) [2570](https://github.com/pallets/flask/pull/2570#discussion_r159909764)
